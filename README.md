# 🚀 Beautiful Terminal Bundle

Этот репозиторий содержит полную конфигурацию для превращения обычного терминала в мощный и красивый инструмент разработчика. Все плагины и скрипты включены в бандл для автономной установки.

## 📋 Требования (Prerequisites)

Перед установкой бандла убедитесь, что в вашей системе установлен **Git**.

### Установка Git:

*   **Linux (Ubuntu/Debian):**
    ```bash
    sudo apt update
    sudo apt install git
    ```
*   **Linux (Arch/Manjaro):**
    ```bash
    sudo pacman -S git
    ```
*   **macOS (Homebrew):**
    ```bash
    brew install git
    ```
*   **Windows:** Скачайте установщик с [git-scm.com](https://git-scm.com/).

## 🌟 Что внутри:
*   **Zsh + Oh My Zsh** — современная оболочка.
*   **Тема `ys`** — чистая, информативная и цветная.
*   **Скрытый Prompt** — ваш `user@hostname` скрыт для чистоты скриншотов.
*   **zsh-autosuggestions** — интеллектуальное автодополнение на основе истории.
*   **zsh-syntax-highlighting** — подсветка синтаксиса.
*   **Tealdeer (tldr)** — невероятно быстрые и понятные справки по командам.
*   **LSD (LSDeluxe)** — современная замена `ls` с иконками и цветами.
*   **Bat** — замена `cat` с подсветкой синтаксиса и нумерацией строк.
*   **FZF** — сверхбыстрый поиск по файлам и истории (Ctrl+R).
*   **Btop** — потрясающий графический монитор ресурсов.
*   **Zoxide** — умная команда `cd`, которая понимает вас с полуслова.
*   **FD** — очень быстрая и интуитивная замена `find`.
*   **GRC** — автоматическая раскраска вывода команд.
*   **ASN** — мощная утилита для разведки IP-адресов и сетей.

## 🛠 Установка одной командой:

После установки Git склонируйте этот репозиторий и запустите скрипт установки:

```console
$ git clone https://github.com/M0NDsuChTiG/beautiful-terminal.git
$ cd beautiful-terminal
$ bash install.sh
```

## ⌨️ Горячие клавиши:
*   `→` (стрелка вправо) — принять предложенное автодополнение.
*   `Ctrl + R` — умный поиск по истории команд (fzf).
*   `ls` — современный список файлов (через `lsd`).
*   `cat <файл>` — просмотр файла с подсветкой (через `bat`).
*   `z <папка>` — быстрый переход в часто посещаемую папку (zoxide).
*   `btop` — красивый мониторинг ресурсов.
*   `tldr <команда>` — быстрая справка.
