[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](https://github.com/M0NDsuChTiG/beautiful-terminal/pulls)

Полная конфигурация для превращения обычного терминала в мощный и красивый
инструмент разработчика. Все плагины и скрипты включены в бандл для автономной
установки. Основные пакеты ставятся через системный пакетный менеджер, а часть
утилит подтягивается бинарниками с GitHub Releases только там, где их нет
в стандартных репозиториях.

## Последние изменения

- `install.sh` переписан как кроссплатформенный установщик: `apt`, `pacman`,
  `dnf`, `zypper` и `brew` — теперь один файл вместо нескольких.
- Пакеты ставятся **поштучно** с проверкой наличия в репозитории: отсутствующее
  не роняет установку, а честно помечается как пропущенное.
- Добавлен `run_root` — единая обёртка над `sudo`, пакетный менеджер всегда
  запускается под root (достаточно один раз ввести пароль).
- GitHub fallback выбирает ассеты **по ОС и архитектуре** (Darwin/Linux,
  x86_64/aarch64/armv7l), а не первый подходящий: на macOS больше не скачивается
  linux-бинарник, а на armv7 — amd64.
- Формат fastfetch с GitHub зависит от пакетного менеджера: `.deb` на `apt`,
  `.rpm` на `dnf`/`zypper`, иначе `tar.gz`. `kmon` ставится только на Linux x86_64.
- Итоговый отчёт честный: «нет в репозитории», «ошибки установки» и число
  недостающих утилит показываются отдельно, а не прячутся за «всё готово».
- README приведён в соответствие с текущей схемой установки.

## Поддерживаемые ОС

| Семейство       | Пакетный менеджер | Статус          |
|-----------------|-------------------|-----------------|
| Debian / Ubuntu | `apt`             | ✅ Полная       |
| Arch / Manjaro  | `pacman`          | ✅ Полная       |
| Fedora / RHEL   | `dnf`             | ✅ Полная       |
| openSUSE        | `zypper`          | ✅ Полная       |
| macOS           | `brew`            | ✅ Полная       |
| Windows         | —                 | ⚠️ Ручная       |

## Требования

- **Git** (установите через ваш пакетный менеджер или [git-scm.com](https://git-scm.com/))
- Права `sudo` на Linux для установки пакетов (кроме случая запуска от root;
  пароль запрашивается один раз и держится живым на время установки)
- Архитектуры Linux: `x86_64`, `aarch64`, `armv7l`; macOS: `x86_64`, `arm64`
  (для остальных GitHub-fallback честно пропускается)

## Установка

```console
$ git clone https://github.com/M0NDsuChTiG/beautiful-terminal.git
$ cd beautiful-terminal
$ bash install.sh
```

Скрипт определит пакетный менеджер (`apt` / `pacman` / `dnf` / `zypper` / `brew`),
поштучно установит доступные пакеты (отсутствующие в репозитории — честный пропуск),
создаст недостающие симлинки (`batcat`→`bat`, `fdfind`→`fd` на Debian) и добавит
бинарниками с GitHub Releases только те утилиты, которых в системе всё ещё нет.

### Как выбираются бинарники с GitHub

- ассеты подбираются по **ОС и архитектуре** (`uname -s` / `uname -m`,
  Darwin→macos, Linux→linux, x86_64/aarch64/armv7l);
- выбор формата fastfetch зависит от PM: `.deb` на `apt`, `.rpm` на `dnf`/`zypper`;
- файлы контрольных сумм (`.sha256`, `.sha512`, `.sig`, `checksums.txt`) отбрасываются,
  чтобы первым не совпал не бинарник;
- `kmon` в релизах есть только для Linux x86_64 — на других архитектурах он пропускается
  с предупреждением, на macOS не ставится вовсе;
- для неизвестной архитектуры берётся `unknown` — такой ассет не скачается «по ошибке»,
  утилита будет честно пропущена.

### Отчёт после установки

В конце скрипт показывает проверку каждой утилиты (`✅`/`❌`), отдельные списки
пропущенных пакетов (`нет в репозитории`), неудавшихся (`ошибки установки`) и итог:
«ГОТОВО. Все основные утилиты на месте» или «ГОТОВО с пропусками» с количеством
отсутствующих — и почему это нормально на минимальных/старых репозиториях.

## Состав бандла

| Компонент              | Описание                                                  |
|------------------------|-----------------------------------------------------------|
| **Zsh + Oh My Zsh**   | Современная оболочка с темой `ys`                         |
| **zsh-autosuggestions** | Интеллектуальное автодополнение на основе истории         |
| **zsh-syntax-highlighting** | Подсветка синтаксиса в реальном времени                |
| **Tealdeer (tldr)**   | Быстрые и понятные справки по командам                    |
| **LSD (LSDeluxe)**    | Замена `ls` с иконками и цветами                          |
| **Bat**               | Замена `cat` с подсветкой синтаксиса и нумерацией строк   |
| **FZF**               | Сверхбыстрый поиск по файлам и истории (Ctrl+R)           |
| **Btop**              | Графический монитор ресурсов                              |
| **Kmon**              | Монитор ядра Linux (Linux **x86_64** — в релизах только такие сборки) |
| **Fastfetch**         | Молниеносный вывод информации о системе при старте        |
| **Lazygit**           | Визуальный интерфейс для Git                              |
| **Duf**               | Понятный монитор дискового пространства                   |
| **Micro**             | Интуитивный текстовый редактор с поддержкой мыши          |
| **Procs**             | Замена `ps` с древом процессов и подсветкой               |
| **Zoxide**            | Умная `cd`, запоминающая часто посещаемые папки           |
| **FD**                | Быстрая и интуитивная замена `find`                       |
| **GRC**               | Автоматическая раскраска вывода команд                    |
| **ASN**               | Утилита для разведки IP-адресов и сетей                   |
| **Скрытый Prompt**    | `user@hostname` скрыт для чистоты скриншотов              |

> Примечание: утилиты из репозиториев ставятся системным менеджером через `run_root`.
> Недостающие (`fastfetch`, `lsd`, `lazygit`, `tealdeer`/`tldr`, `procs`, `kmon`,
> `zoxide`) скрипт добирает бинарниками с GitHub Releases с учётом ОС, архитектуры
> и пакетного менеджера.

## Горячие клавиши

| Клавиша               | Действие                                    |
|-----------------------|---------------------------------------------|
| `→` (стрелка вправо)  | Принять предложенное автодополнение          |
| `Ctrl + R`            | Умный поиск по истории команд (FZF)          |
| `ls`                  | Современный список файлов (LSD)              |
| `cat <файл>`          | Просмотр с подсветкой синтаксиса (Bat)       |
| `z <папка>`           | Быстрый переход (Zoxide)                     |
| `btop`                | Мониторинг ресурсов                          |
| `tldr <команда>`      | Быстрая справка                              |
| `lg`                  | Запуск Lazygit                               |
| `df`                  | Список дисков (Duf)                          |
| `ps`                  | Список процессов (Procs)                     |
| `micro <файл>`        | Редактирование текста                        |
| `kmon`                | Управление модулями и мониторинг ядра        |
