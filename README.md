# Beautiful Terminal Bundle

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Shell](https://img.shields.io/badge/Shell-Zsh-%23F15A24?logo=gnu-bash&logoColor=white)](https://www.zsh.org)
[![Oh My Zsh](https://img.shields.io/badge/Oh%20My%20Zsh-✓-blueviolet)](https://ohmyz.sh)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](https://github.com/M0NDsuChTiG/beautiful-terminal/pulls)

Полная конфигурация для превращения обычного терминала в мощный и красивый
инструмент разработчика: Zsh + Oh My Zsh, современные CLI-утилиты (lsd, bat,
fzf, btop, zoxide и другие), плагины zsh-autosuggestions и
zsh-syntax-highlighting, а также утилита сетевой разведки `asn`. Все плагины
и скрипты включены в бандл для автономной установки — без зависимостей от
внешних репозиториев (кроме системных пакетов). Полностью поддерживается на
Linux (Debian/Ubuntu, Arch, Fedora, openSUSE); на macOS — частичная поддержка
(подробности в разделе «Поддерживаемые ОС»).

## Поддерживаемые ОС

| Семейство       | Пакетный менеджер | Статус                      |
|-----------------|-------------------|-----------------------------|
| Debian / Ubuntu | `apt`             | ✅ Полная                   |
| Arch / Manjaro  | `pacman`          | ✅ Полная                   |
| Fedora / RHEL   | `dnf`             | ✅ Полная                   |
| openSUSE        | `zypper`          | ✅ Полная                   |
| macOS           | `brew`            | ⚠️ Частичная (best-effort)  |
| Windows         | —                 | ⚠️ Ручная                   |

> **macOS — частичная поддержка (best-effort).** Linux-дистрибутивы
> (Debian/Ubuntu, Arch, Fedora, openSUSE) поддерживаются полностью. На macOS
> установка возможна, но с ограничениями:
>
> - `kmon` — монитор ядра, доступен только для Linux и отсутствует в Homebrew,
>   поэтому на macOS пакет пропускается;
> - `readlink -f` отсутствует в BSD/macOS — определение каталога бандла может
>   работать некорректно;
> - утилита `bin/asn` требует bash ≥ 4.2, тогда как в macOS по умолчанию
>   bash 3.2;
> - шаги `install_asn` и `switch_shell` вызывают `sudo` даже при установке
>   через brew, а каталог `/usr/local/bin` может отсутствовать на Apple
>   Silicon.

## Требования

- **Git** (установите через ваш пакетный менеджер или [git-scm.com](https://git-scm.com/))
- Права `sudo` на Linux и macOS для установки пакетов и смены оболочки

## Установка

```console
$ git clone https://github.com/M0NDsuChTiG/beautiful-terminal.git
$ cd beautiful-terminal
$ bash install.sh
```

Скрипт автоматически определит ваш пакетный менеджер, установит всё необходимое
и настроит Zsh с плагинами. Установка идемпотентна: уже установленные пакеты и
компоненты не переустанавливаются, а пакеты, отсутствующие в репозиториях
дистрибутива, пропускаются с предупреждением, не прерывая установку.
Существующий `~/.zshrc` перед заменой сохраняется в резервную копию
`~/.zshrc.bak.YYYYMMDD-HHMMSS`. На macOS установка возможна с ограничениями —
см. раздел «Поддерживаемые ОС».

| **Kmon**              | Интерактивный монитор ядра Linux                          |
| **Fastfetch**         | Молниеносный вывод информации о системе при старте        |
| **Lazygit**           | Визуальный интерфейс для Git                              |
| **Duf**               | Понятный монитор дискового пространства                   |
| **Micro**             | Интуитивный текстовый редактор с поддержкой мыши          |
| **Procs**             | Замена `ps` с древом процессов и подсветкой               |

| **FD**                | Быстрая и интуитивная замена `find`                       |
| **GRC**               | Автоматическая раскраска вывода команд                    |
| **ASN**               | Утилита для разведки IP-адресов и сетей                   |
| **Тема `ys`**        | Приглашение `user@host` с веткой Git и статусом каталога  |

## Горячие клавиши

| Клавиша               | Действие                                    |
|-----------------------|---------------------------------------------|
| `→` (стрелка вправо)  | Принять предложенное автодополнение          |
| `Ctrl + R`            | Умный поиск по истории команд (FZF)          |
| `ls`                  | Современный список файлов (LSD)              |
| `cat <файл>`          | Просмотр с подсветкой синтаксиса (Bat)       |
| `z <папка>`           | Быстрый переход (Zoxide)                     |
| `btop`                | Мониторинг ресурсов                          |
| `tldr <команда>`      | Быстрая справка                              |
| `lg`                  | Запуск Lazygit                               |
| `df`                  | Список дисков (Duf)                          |
| `ps`                  | Список процессов (Procs)                     |
| `micro <файл>`        | Редактирование текста                        |
| `kmon`                | Управление модулями и мониторинг ядра        |

## Последние изменения

- **install.sh: устойчивая установка пакетов.** Пакеты, отсутствующие в
  репозиториях дистрибутива, теперь пропускаются с предупреждением вместо
  прерывания всей установки (apt/pacman проверяют доступность до установки,
  dnf/zypper/brew при сбое массовой установки переходят к установке по одному
  и пропускают недоступные). Ограничение: действительно неудачная установка
  (ошибка сети или репозитория) по-прежнему останавливает скрипт.
- **install.sh: fallback на GitHub Releases для Ubuntu 24.04.** Если пакеты
  fastfetch, lazygit или procs отсутствуют в стандартных репозиториях apt на
  Ubuntu 24.04, скрипт автоматически скачивает свежие бинарные релизы
  напрямую из GitHub Releases, делает их исполняемыми и помещает в
  `/usr/local/bin`. Пакеты, не попавшие под этот fallback (например, пакеты,
  которых нет и в GitHub Releases), по-прежнему пропускаются с предупреждением.
- **New/index.html: интерактивный демо-терминал.** На лендинге добавлен
  демонстрационный терминал с цветным приглашением и реалистичным
  многоцветным выводом для команд fastfetch, ls -la, ps, z Downloads, btop,
  lazygit, tldr bat, df, clear, help (поддерживаются и русские аналоги:
  помощь, очистить, z Загрузки).
