# Beautiful Terminal Bundle

[![Shell](https://img.shields.io/badge/Shell-Zsh-%23F15A24?logo=gnu-bash&logoColor=white)](https://www.zsh.org)

[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](https://github.com/M0NDsuChTiG/beautiful-terminal/pulls)

Полная конфигурация для превращения обычного терминала в мощный и красивый
инструмент разработчика. Все плагины и скрипты включены в бандл для автономной
установки — без зависимостей от внешних репозиториев (кроме системных пакетов).

## Поддерживаемые ОС

| Семейство       | Пакетный менеджер | Статус          |
|-----------------|-------------------|-----------------|
| Debian / Ubuntu | `apt`             | ✅ Полная       |
| Arch / Manjaro  | `pacman`          | ✅ Полная       |
| Fedora / RHEL   | `dnf`             | ✅ Полная       |
| openSUSE        | `zypper`          | ✅ Полная       |
| macOS           | `brew`            | ✅ Полная       |
| Windows         | —                 | ⚠️ Ручная       |

## Требования

- **Git** (установите через ваш пакетный менеджер или [git-scm.com](https://git-scm.com/))
- Права `sudo` на Linux (кроме Arch) для установки пакетов

## Установка

```console
$ git clone https://github.com/M0NDsuChTiG/beautiful-terminal.git
$ cd beautiful-terminal
$ bash install.sh
```

Скрипт автоматически определит ваш пакетный менеджер, установит всё необходимое
и настроит Zsh с плагинами.

## Состав бандла

| Компонент              | Описание                                                  |
|------------------------|-----------------------------------------------------------|
| **Zsh + Oh My Zsh**   | Современная оболочка с темой `ys`                         |
| **zsh-autosuggestions** | Интеллектуальное автодополнение на основе истории         |
| **zsh-syntax-highlighting** | Подсветка синтаксиса в реальном времени                |
| **Tealdeer (tldr)**   | Быстрые и понятные справки по командам                    |
| **LSD (LSDeluxe)**    | Замена `ls` с иконками и цветами                          |
| **Bat**               | Замена `cat` с подсветкой синтаксиса и нумерацией строк   |
| **FZF**               | Сверхбыстрый поиск по файлам и истории (Ctrl+R)           |
| **Btop**              | Графический монитор ресурсов                              |
| **Kmon**              | Интерактивный монитор ядра Linux                          |
| **Fastfetch**         | Молниеносный вывод информации о системе при старте        |
| **Lazygit**           | Визуальный интерфейс для Git                              |
| **Duf**               | Понятный монитор дискового пространства                   |
| **Micro**             | Интуитивный текстовый редактор с поддержкой мыши          |
| **Procs**             | Замена `ps` с древом процессов и подсветкой               |
| **Zoxide**            | Умная `cd`, запоминающая часто посещаемые папки           |
| **FD**                | Быстрая и интуитивная замена `find`                       |
| **GRC**               | Автоматическая раскраска вывода команд                    |
| **ASN**               | Утилита для разведки IP-адресов и сетей                   |
| **Скрытый Prompt**    | `user@hostname` скрыт для чистоты скриншотов              |

## Горячие клавиши

| Клавиша               | Действие                                    |
|-----------------------|---------------------------------------------|
| `→` (стрелка вправо)  | Принять предложенное автодополнение          |
| `Ctrl + R`            | Умный поиск по истории команд (FZF)          |
| `ls`                  | Современный список файлов (LSD)              |
| `cat <файл>`          | Просмотр с подсветкой синтаксиса (Bat)       |
| `z <папка>`           | Быстрый переход (Zoxide)                     |
| `btop`                | Мониторинг ресурсов                          |
| `tldr <команда>`      | Быстрая справка                              |
| `lg`                  | Запуск Lazygit                               |
| `df`                  | Список дисков (Duf)                          |
| `ps`                  | Список процессов (Procs)                     |
| `micro <файл>`        | Редактирование текста                        |
| `kmon`                | Управление модулями и мониторинг ядра        |
