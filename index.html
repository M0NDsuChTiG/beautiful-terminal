Beautiful Terminal Bundle

Ультимативный набор для прокачки твоего Linux терминала до уровня PRO. Toolkits 1-9

git clone https://github.com/M0NDsuChTiG/beautiful-terminal.git && cd beautiful-terminal && bash install.sh

🎨 Визуальный экстаз

Zsh с темой 'ys', иконки через LSD и подсветка синтаксиса делают работу приятной глазу.

⚡ Скорость мысли

Интеллектуальное автодополнение и нечеткий поиск через FZF позволяют находить команды за доли секунды.

🛠 Мощный инструментарий

В комплекте: Btop, Fastfetch, Lazygit, Kmon, Zoxide и многое другое.

📂 Умная навигация

Забудьте про скучный cd. Используйте Zoxide, который запоминает ваши любимые пути.

Создано с любовью к открытому коду и терминалам.
Настроено с помощью Gemini CLI 🤖
