# Демо-лендинг Beautiful Terminal

Одностраничный лендинг бандла **Beautiful Terminal** для GitHub Pages:
концепция, сравнительная аналитика CLI-утилит, каталог компонентов,
интерактивный демо-терминал и справка по горячим клавишам.

## Содержимое

- `index.html` — сама страница (HTML + встроенные CSS и JS);
- `Интерактивный лендинг для Beautiful Terminal - Google Gemini.pdf` — макет-референс.

## Как открыть локально

Просто откройте `index.html` в браузере — внешних зависимостей сборки нет
(шрифты, Tailwind и Chart.js подгружаются из CDN при наличии интернета).

```bash
# либо через локальный HTTP-сервер:
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Демо-терминал

В разделе «Демо-терминал» можно вводить команды: `fastfetch`, `ls -la`,
`ps`, `z Downloads`, `btop`, `lazygit`, `tldr bat`, `df`, `clear`, `help`
(работают русские аналоги: `помощь`, `очистить`, `z Загрузки`).
